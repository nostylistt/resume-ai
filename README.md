# Resumatch

Бакалаврська робота – вебзастосунок для аналізу резюме та його відповідності вимогам вакансій. Користувач завантажує резюме, отримує оцінку структури й тексту, порівняння навичок із ринком праці та може зберегти звіт у PDF.

## Можливості

- Реєстрація, вхід і відновлення пароля.
- Аналіз резюме у форматах PDF, DOC і DOCX. Максимальний розмір файлу: 10 МБ.
- Витягування тексту та визначення розділів резюме.
- Оцінювання структури, тексту й відповідності навичок ринковим вимогам.
- Збір вимог із сайтів вакансій DOU, Work.ua та Robota.ua.
- Історія попередніх аналізів і експорт результатів у PDF.
- Покращення формулювань у резюме.

## Як працює аналіз

1. Користувач завантажує файл через вебінтерфейс.
2. Сервер перевіряє формат і розмір, після чого витягує текст за допомогою MuPDF або Mammoth.
3. Текст перевіряється на відповідність резюме та розбирається на секції.
4. Аналіз структури й тексту запускається паралельно зі збором ринкових вимог для визначеної позиції.
5. Навички з резюме порівнюються з вимогами вакансій, формується підсумок і результат зберігається в PostgreSQL.
6. Користувач переглядає результат, відкриває його з історії або експортує у PDF.

Ринкові дані кешуються в SQLite на 48 годин. Якщо даних про вакансії недостатньо, система повертає результат аналізу резюме без повного ринкового профілю.

## Технології

- Клієнт: React, TypeScript, Vite.
- Сервер: Node.js, Express.
- Основна база даних: PostgreSQL.
- Кеш ринкових даних: SQLite.
- Обробка документів: MuPDF, Mammoth.
- Аналіз і покращення тексту: OpenAI API.
- Генерація PDF: Puppeteer.

## Локальний запуск

Потрібні Node.js, npm і доступ до PostgreSQL. Для повного аналізу також потрібен ключ OpenAI API. Для відновлення пароля потрібні облікові дані Resend.

### 1. Налаштуйте базу даних

Створіть базу PostgreSQL і застосуйте схему з кореня проєкту:

```bash
psql -h localhost -U your_database_user -d your_database_name -f migrations/schema.sql
```

### 2. Налаштуйте сервер

Створіть `server/.env` на основі `server/.env.example` і вкажіть параметри PostgreSQL, `JWT_SECRET` та `OPENAI_API_KEY`. Для листів відновлення пароля налаштуйте `RESEND_API_KEY` і `EMAIL_FROM`.

```bash
cd server
npm install
node server.js
```

Сервер за замовчуванням працює на `http://localhost:4000`. Перевірити доступність можна за адресою `http://localhost:4000/health`.

### 3. Налаштуйте клієнт

Створіть `client/.env` на основі `client/.env.example`. Для локального запуску API має вказувати на `http://localhost:4000/api`.

```bash
cd client
npm install
npm run dev
```

Vite покаже адресу локального клієнта, зазвичай `http://localhost:5173`.

## Змінні середовища

Приклади налаштувань розміщені у `server/.env.example` та `client/.env.example`. Секрети й робочі `.env` файли не слід додавати до системи контролю версій.

## Структура проєкту

```text
client/       React-клієнт
server/       Express API та сервіси аналізу
migrations/   SQL-схема PostgreSQL
```

## API

Основні маршрути сервера:

- `GET /health` — перевірка стану сервера.
- `/api` — реєстрація, вхід, вихід, відновлення пароля та профіль.
- `/api/resume` — завантаження й аналіз резюме, історія, покращення тексту та PDF-експорт.

Більшість маршрутів роботи з резюме потребують авторизації.
